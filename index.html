研究與教育原型

交易由瀏覽器中的 JavaScript 狀態機模擬；Solidity 合約另附原始碼，未接入真實區塊鏈。風險分析為規則式教育工具，不構成安全保證。

    📚 研究與使用限制

    本網站使用 JavaScript 狀態機執行交易規則，並提供獨立 Solidity 教學合約。網頁沒有連接區塊鏈、沒有使用真實資金，也沒有即時偵測詐騙的能力。

    託管規則可以限制某些未授權提款行為，但無法自動證明商品是否交付，也無法保證防止假網站、社交工程、惡意合約或仲裁失職。
